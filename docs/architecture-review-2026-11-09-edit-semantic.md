## 1. E-1：第 4 级只写了降级路径，没写机械与判定的分工（P1）

### 1.1 现象

§5.4 此前对第 4 级写了两样东西：**一张现象—判断—动作的表**（相似片段 / 多处相似 /
内容变了 / 完全找不到），和一段**降级路径**（判定不可用即机械归因）。但**判定可用
时的正常路径没写**——具体说，下面三件事没定：

1. 判定是**每一步都调**，还是**只在机械手段用尽后调**？
2. 判定**问什么**、**产出什么**？
3. 「最像的位置」由谁给？

这三件事不定，实现就有一个很自然的默认：**先调判定，让它找位置**。这看起来最
简单，但有两个问题：把机械能做的（算相似度）交给了模型，违反本节「为什么不是
全部交给模型」的既有判断；而且判定**给不出位置**（§3.2 的 span 仅在「要求定位时
返回」，systemone 不返回 span），所以「让判定找位置」这条路在协议层就不通。

### 1.2 补齐：机械分诊在前，判定只答规则答不了的

**机械分诊在前。** 第 1、2、3 级都没命中时，先用相似度算出最像的候选。
**相似度低于阈值就直接按「根本不存在」走机械归因，不调用判定**——理由与本节
「为什么不是全部交给模型」一致：机械能解决的用规则解决，模型只处理规则覆盖不到
的。用模型回答机械能答的问题是拿数百毫秒换 0ms 就能做对的事，还引入不确定性
（同一个 edit 两次可能给出不同结果，§16.3 对策二）。

**判定只答规则答不了的**，一次调用问六个二元问题：差异类型五选一（上下文不足 /
文件已变 / 格式差异 / 歧义 / 根本不存在）+ 「能否安全应用」。`failure_kind` 取
差异类型里概率最大者（差异类型互斥，取最大即可）。

**位置不交给判定。** 最像候选的位置由工具层用**机械相似度**给出——位置本来就是
机械相似度的产物，判定给不出更准的（systemone 不返回 span，§3.2）。**判定只回答
差异类型与能否安全应用。**

**state 有界。** `oldText` 与候选片段各截断到约 2000 字符，加路径与候选行号
（§6.4 的有界窗口口径）。

**命中多处即拒绝**（承接本节硬约束 2）：相似度算出多处候选时**不猜**——先由判定
确认「是不是歧义」，是则列出全部候选行号并拒绝，等调用方补上下文。判定的作用
是「确认歧义」而不是「挑一个」。

### 1.3 落点

04-tools.md §5.4：新增「第 4 级的落地口径：机械分诊在前，判定只答规则答不了的」
小节（与既有的第 4 级表格、伪代码段衔接，不重复）。

## 2. E-2：判定驱动的写操作没有比只读判定更严的门控（P1）

### 2.1 现象

§7.2 的三档门控（p ≥ 0.85 采用 / 0.60–0.85 低置信 / < 0.60 两视图）管的是
**内容可信度**：「这个判定能不能拿给调用方看」。第 4 级的判定结论要**驱动写操作**
（归一化后写回文件），但正文没说这档判定该受不受同样的门控约束。

若照搬只读门控，0.60–0.85 档的判定会被「采用」并写回文件——**一个只有六成把握
的判断直接改了用户的代码**。

### 2.2 补齐：叠一层不可逆性约束

| 门控档位 | 只读判定 | 驱动写操作 |
|---|---|---|
| p ≥ 0.85 | 采用 | **允许自动写回** |
| 0.60 ≤ p < 0.85 | 采用 + 标 LOW_CONFIDENCE | **不自动改**：报错 + 归因 + 建议，把决定权交回调用方 |
| p < 0.60 | 两视图都给 | **不自动改**：同上 |

**理由是不可逆性不对称**：只读判定错了只是结论错；写操作错了是**文件被改了**。
§18.5 的写前复核与 §20 的写前快照是**兜底**，不是「可以放宽门控」的理由——它们能
让文件事后恢复，不能让一个六成把握的判断去动代码。

**这是在既有门控之上叠加，不是另立一套阈值**：三档的阈值不变（0.85 / 0.60），变的
是**低置信档能否自动写回**。只读判定可以（标了 LOW_CONFIDENCE，调用方自己判断），
写操作不行——调用方要拿到的是「没改」，不是「改了但你小心点」。

**不自动改时的返回形态**：按 §1.4.5 的 ToolError 三段式返回，给归因
（`failure_kind`）与建议（机械映射，见 E-3），`nextSteps` 让调用方选择补上下文
重试 / 缩小范围 / 强制指定位置。**这与「判定不可用时的机械归因」是同一个出口**——
写操作要么确定地改，要么确定地不改并说清楚为什么。

### 2.3 落点

06-cost.md §7.2：新增「判定驱动的写操作：比只读判定更严」小节。

## 3. E-3：suggestion 的产出方未定（P2）

### 3.1 现象

§5.4 的伪代码段里，判定问三个问题：`failure_kind?`、`fixable?`、
`suggestion?`——**第三个是「建议扩大上下文 / 重新 read / 确认路径 / 重算 hunk」**，
这是一句自由文本。

但 §3.2 的 decide 槽位契约**没有自由文本输出**——它只给每个问题一个概率。所以
「让判定生成 suggestion」要么需要一个契约外的输出通道，要么是把 suggestion 编码
成一个「选哪个建议」的分类问题（那本质上是 choice 类型，而 §3.10 的适配器本轮只
映射 `noul`）。

### 3.2 补齐：建议由 failure_kind 机械映射

**「失败原因 → 建议」是工具层按 `failure_kind` 查表得到的确定性映射**，不由判定
生成。理由与 §5.1 的归并规则同理：判定只给概率，字段值由工具层按规则合成。

这样也顺带解决了「措辞不受控、无法测试、多一次生成开销」三个问题——建议是查表
出来的，措辞固定、可写快照测试、不占生成预算。

### 3.3 落点

04-tools.md §5.4 同一小节（与 E-1 的补齐写在一处）。

## 4. E-4：「confidence 取所有问题最小值」让门控失效（P1，本轮实测发现）

### 4.1 现象

上一轮正文写的 confidence 口径是「**多问题时取各问题概率的最小值**」——理由是
「最不确定的那个决定本次结论的可信度」。**本轮实测证明这个口径是错的。**

cli-wire 在本机真实判定服务上的实测：

| 场景 | 实测 | 旧口径取到的 confidence | 后果 |
|---|---|---|---|
| edit 场景 1 | `file_changed` 问 0.5191（**argmax 正确、归因也对**）；`format` 问 0.0096 | 0.01 | < 0.85 → 不写回 |
| edit 场景 2 | `format` 问 0.2319（argmax 正确）；其余问 0.19 / 0.13 | 0.11 | < 0.85 → 不写回 |
| bash | confidence 恒为 0.05–0.07 | 0.05–0.07 | 门控恒为 both_views |

### 4.2 根因

**多选问题的非答案概率天然极低**——非答案本来就该是低概率（问「是不是格式差异」
而答案不是它，概率就该接近 0）。用「全部问题的最小值」当置信度，等于**把任何
多问题判定都压到低置信档**：§7.2 的三档门控在这些工具上形同虚设，判定等于没被
采用，**却白付一次模型调用的延迟**。edit 场景 1 尤其说明问题——判定明明是**对的**
（argmax 正确、归因也对），却因为「不是答案的那一类概率低」而被门控否掉。

### 4.3 新口径

**confidence = 本次被采纳结论所依赖的问题概率的最小值**——不是「所有问题的最小
值」：

| 工具 | confidence 取值 |
|---|---|
| bash | min(`has_error` 的概率, **被选中** kind 类别概率)；判定为「无错」时取 `has_error` 概率本身 |
| edit | min(**被选中** `failure_kind` 概率, `fixable` 概率) |

「被选中类别」指 argmax 命中的那一类。**置信度该衡量「这条结论有多可信」，不是
「所有问题都多确定」**——被采纳的结论只依赖那几个问题，其余问题的低概率是
「它们不是答案」的正常表达，不该拖累这条结论的可信度。

### 4.4 落点

06-cost.md §7.3「槽位状态与 confidence 的真实来源」（改口径 + 给理由 + 附实测
数字）；04-tools.md §5.1（bash 的取值）与 §5.4（edit 的取值）同步；§7.2 的写操作
门槛**数值不变**（0.85），但写明它作用在**新口径的 confidence** 上。

### 4.5 连带观察：第 4 级的自动应用在当前模型下偏紧

新口径下 edit 的 `format` 类实测置信度仍只有约 0.23，远低于 0.85，所以第 4 级
**在实践中多数走「不写回 + 归因 + 建议」这一支**。**这是门槛在起作用，不是缺陷**
（写操作本来就该谨慎）；但它说明「自动应用」这条路需要更明确的模型或更细的分解
才能达到门槛。**作为待观测项**：edit 自动应用率与判定准确率按 §15.6 的「判定准确
率」指标一起观测，达标前不放松门槛。
