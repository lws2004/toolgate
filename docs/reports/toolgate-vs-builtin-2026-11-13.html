一、结论摘要

核心结论：toolgate 在 edit（行锚点/整段 diff）、task（后台长任务）、大输出落盘 spill、本地摘要/看图/结构化判定 上明显强于内置工具；但代价是 每个请求固定 2.0–2.4K token 的工具定义开销（超 1.5K 红线）、无 shell 导致 bash 表达力受限、以及 摘要链路约 26s 的高延迟。适合作为「重活 / 敏感数据不出本机」的补充工具层与内置工具并存，而非全面替换。本轮新增的敏感度标注与输入去重只加告知与 meta，不改返回形态；代价是 ≥500 token 的 auto 调用多约 3.1s。
最关键的一条实测：槽位配置后，MCP 通道（即 DSH 内的真实调用路径）直接返回了准确摘要——说明配置对运行中的 MCP server 即刻生效，无需重启。默认 intent=raw 不会摘要（设计如此，§5.1），必须显式 intent=summary/auto 且输出 ≥500 token 才触发。

四·补二　输出敏感度标注与模型输入去重（2026-11-13 新增）

两项新增都不改变返回形态：敏感度只追加 [SENSITIVE] level=... 告知与 meta.sensitivity，原文不脱敏；去重只作用于送给 decide/summarize 的模型输入，content 与行号保持原样。
  • 敏感度标注（classify + 机械正则取高）：600 行 API key 样本 → level=secret、source=mechanical，content 第二行为 [SENSITIVE] level=secret，structured notices 含 {"code":"SENSITIVE","params":{"level":"secret"}}；600 行邮箱 → personal/mechanical；正常 Cargo.lock → normal、score=0.99、source=classify。DSH MCP 通道同样返回告知。
  • 为什么需要机械保底：d3-nano classify 对上述两个高危样本都判 normal（0.98 / 0.95）。实现改为「classify 与机械正则并行取更高等级、机械正则作下限」，架构正文已同步（04 §5.1/§5.2/§5.5、03 消费点、15 §17.2）。
  • 成本：600 行 bash intent=auto 端到端 3.11–3.15s（intent=raw 0.00s，不判定）；100 行 read 去重摘要 0.65–0.78s（raw 0.00s）。标注只在非 raw 且 ≥500 token 时触发，轻量读取零成本。
边界：search 只在 content 模式标注；read 的 sensitivity 仍由 decide 十问判定，不重复调 classify；去重窗口 50–200 行、embedding 不可用即回退原窗口，且不因此发 SLOT_UNAVAILABLE（附加标签不改变返回形态的显式例外）。

六、关键风险与限制

① 无 shell（安全设计，也降低通用性）：toolgate bash 拒绝 sh -c，不支持管道/重定向/变量展开；复杂 shell 组合必须改用内置 bash。
② 高延迟：摘要端到端约 26s（400 行），图片读取约 6s，交互式高频调用不可取。
③ 默认不摘要：intent=raw 为默认，须显式 summary/auto 且输出 ≥500 token 才触发。
④ 判定置信偶低：decide 对模糊输入给 LOW_CONFIDENCE（实测 p=0.38, errorKind=unknown），需调用方容忍降级。
⑤ 常驻开销：每次请求 ≈2.0–2.4K token，超红线。
⑥ 部署依赖：summarize 依赖 LFM2.5:10031、vision 依赖 MiniCPM-V:10014、decide 依赖 d3-nano:8082（该实例未加载 mmproj，带图判定不可用）；须三者常驻，否则槽位降级机械路径。
⑦ 路径细节：MCP server 工作目录为 /Users/lanws/workspace（非会话 cwd），相对路径易解析到非预期目录；search files 模式路径前缀偶有显示不一致（非数据损坏）。
⑧ rerank query 复用：search 用同一 query 作正则匹配与 rerank 语义查询，关键词/正则作 rerank 查询语义弱，实测可把最相关命中排到最后（query="database" 时 hi 句 0.522 排末、无关句 0.608 排首）；只有自然语言 query 才有正收益。
⑨ classify 会漏判：d3-nano 对 600 行邮箱 / API key 样本判 normal（0.98 / 0.95），故输出标注取「classify 与机械正则更高等级、机械保底」；正常文本不受影响。
⑩ 标注有延迟成本：600 行 bash intent=auto 端到端约 3.1s（decide + classify），intent=raw 为 0.00s；只在 ≥500 token 非 raw 输出触发。
